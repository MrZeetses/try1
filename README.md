# Ресторан восточной кухни «Самарканд» — Cloud ERP + POS/KDS + Витрина гостя

## Быстрый старт

1. Распакуйте архив и установите зависимости:
   ```bash
   npm install
   ```
2. Создайте проект в [Supabase](https://supabase.com/), откройте **SQL Editor** и выполните файл `supabase/schema.sql`.
3. Запустите приложение:
   ```bash
   npm run dev
   ```
4. Введите `SUPABASE_URL` и `SUPABASE_ANON_KEY` в открывшемся окне подключения (или укажите их в `.env`).
